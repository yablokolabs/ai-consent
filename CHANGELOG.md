# Changelog

All notable changes to AI-Consent will be documented in this file.

## [0.1.0] - 2026-08-23

### Added
- Initial release of AI-Consent
- EU AI Act risk classifier (deterministic, no LLM required)
- Compliance readiness scoring engine (0-100) across 9 dimensions
- Evidence-based scoring with confidence levels
- Remediation engine with prioritized plans
- 11 MCP tools for programmatic assessment
- CLI with `scan` and `classify` commands
- Agent manifest format (ai-consent.yaml)
- 5 example manifests (recruitment, support, healthcare, logistics, summarizer)
- FastMCP server for MCPize deployment
- Docker support
- GitHub Actions CI
